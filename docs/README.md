# Docs

| Path | Holds |
|---|---|
| [`../GLOSSARY.md`](../GLOSSARY.md) | Domain language: one term per concept, with the words to avoid. |
| `adr/` | Architecture decisions, numbered in order, one per decision. |
| `agents/` | Agent configuration files. |
| `specs/` | Settled product specs, dated the day they were settled. |
| `examples/` | Sample output kept as a reference, not part of the product. |

## Naming

- Product specs: `YYYY-MM-DD-<topic>.md`.
- ADRs: `NNNN-<slug>.md`, numbered in order.
