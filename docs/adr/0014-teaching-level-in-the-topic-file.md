# The teaching level lives in the topic file

Status: accepted, 2026-10-30.

`study` had one writing standard for every learner. A reader meeting a subject for the first time and a reader reviewing it for a project got the same step size and the same amount of explanation, and neither could state the difference once for the topic. ChatGPT Study Mode answers this with a calibration question, and ADR 0003 already names its weak point: there the answer becomes the level, even when the learner is wrong about what they know.

Approval now asks one calibration round, merged into the skip question. The answers become three optional lines in `graph.md`: `Goal`, `Background`, and `Teaching level`, the last one taking `beginner`, `standard`, or `advanced`. A missing line means `standard`, so no existing topic changes. `study-plus` passes the three lines verbatim, and `study` treats them as writing context without reading a tracker file, which keeps the one-way dependency from [ADR 0008](0008-study-mode-is-a-global-overlay.md). The level changes the lecture only: no question count, no pass bar, no state, no log entry. A mid-topic change lasts for the session, and only an explicit "from now on" rewrites the one line. The calibration keeps the `skipped` row that [ADR 0003](0003-skipped-is-a-self-report.md) describes, now as the third item of the same round, and none of the answers counts as evidence, per [ADR 0005](0005-teaching-is-not-evidence). A wrong self-report is tolerable here because the level only shapes the lecture: it cannot raise a state, pass a prerequisite, or soften a question.

Alternatives. A settings field was rejected: the level belongs to one topic, not to the profile. A fourth tracker file was rejected: it adds a file for three lines. Letting `study` read `graph.md` was rejected: it breaks the one-way dependency and gives the writing standard a second owner. Inferring the level from the lecture output was rejected: a stated goal is not a measurement of knowledge.
