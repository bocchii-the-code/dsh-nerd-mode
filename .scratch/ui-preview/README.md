# UI directions preview

Run `node .scratch/ui-preview/render.mjs`, then open `preview.html` from disk. No server or network is needed.

Click Light / Dark in a column to theme that direction. Click a name in the header to dim the others; click again to show all.

- **Ledger** — hairline groups and tight rows; a study log.
- **Card** — each setting is a card; generous padding and gaps.
- **Astryx** — the Astryx neutral palette in one framed sheet.
