# Research

Write the source note for one Course, before the concept graph exists. The note is working material for the later roles. It is never evidence, and it never reaches the learner.

## Inputs

- The Course name.
- The subject, in one line.
- The `Goal` and `Background` lines.
- The supplied material: file paths or pasted text.
- The Chapter list, each with its scope.
- The destination `study/<course>/sources.md`.

## Do

- Read the supplied material first.
- Search the web or the literature only for a load-bearing point that the supplied material does not answer.
- Write one file at the destination. Open it with `# Sources: <Course name>` and `Date: <YYYY-MM-DD>`, the day you run.
- Then write one `## <Chapter title>` section per Chapter, in book order.
- Write one bullet per point, shaped `<the point in one sentence> - <source>`.
- Name the file, not a URL, for a point that rests on supplied material.
- Name the site or the author, the title, and the date you read it for a web or book source.
- Write `Gap: <what is missing>` in a Chapter section when no source covers an outcome that Chapter claims.
- Write `Disagreement: <claim> (<source>) vs <claim> (<source>)` on one line when two sources conflict in a way that changes the lesson.
- Name the source of every load-bearing number, definition, and causal claim.
- Mark a fact that only one weak source carries.
- Say what is unknown. Never fill a gap silently.

## Do not

- Write teaching prose, exercises, figures, or lecture text.
- Cite a source you did not read.
- Invent a title, an author, or a URL.
- Pad the note with a source that carries no point.
- Write a second file.
- Take a position on a disagreement when the evidence does not settle it.

## Report

Start with the header lines, then add these below `Judge`:

- `Coverage: <Chapter title> - covered | partial | missing`, one line per Chapter.
- `Gaps: <one line per gap, or "none">`
- `Disagreements: <one line per conflict, or "none">`
